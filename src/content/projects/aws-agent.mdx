## Overview

A serverless AI assistant architected on AWS Lambda that queries a Large Language
Model hosted on Amazon SageMaker, and fetches real-time structured data from S3 —
a working demonstration of agentic tool use on a fully serverless stack.

## The problem

LLM agents are usually deployed behind always-on servers, which is expensive when
traffic is bursty or intermittent. The question I wanted to answer: can a useful
tool-using agent run with no persistent infrastructure at all?

## Approach

The agent answers general queries directly and, when a query needs live data, calls
out to an S3 bucket as a tool — fetching structured records and grounding its response
in them. Lambda orchestrates the request/response flow; SageMaker hosts the model.

## Architecture

```
client → API Gateway → Lambda (orchestrator)
                          ├── SageMaker endpoint (LLM inference)
                          └── S3 (structured data / tool)
```

The whole stack scales to zero when idle, eliminating server-management overhead and
cost during downtime.
