## Overview

A research project implementing AIoT — the combination of AI and the Internet of
Things — for adaptive traffic-signal control at complex urban intersections. A single
Traffic Light agent, trained with deep reinforcement learning, runs directly on edge
hardware.

## The problem

Cloud-based signal control adds a network round-trip to every decision, which hurts
both latency and reliability — exactly the wrong properties for safety-relevant
infrastructure that has to keep working under degraded connectivity.

## Approach

A Traffic Light agent is trained offline within SUMO simulations using a deep
reinforcement learning framework, then deployed to run locally on intersection
hardware.

## Architecture

The edge-first design means the agent runs on the intersection device itself, with no
cloud dependency at inference time — reducing latency and improving reliability when
the network is unreliable.
